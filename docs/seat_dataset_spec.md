# KIA 챔피언스 필드 좌석 마스터 데이터 명세서 (Seat Dataset Spec) - 검증 완료

## 1. 개요
PRD "성공 조건 1"에 따라, 본 서비스의 좌석 구역별 평일/주말 가격 및 블록 정보는 실제 KIA 챔피언스 필드 공식 예매 기준(티켓링크 예매 기준)과 100% 일치하도록 구축 및 검증되었습니다. 본 문서는 애플리케이션 내 정적 데이터셋(`lib/seat-data.ts`)의 마스터 스키마와 데이터 정의를 기술합니다.

---

## 2. 데이터 스키마 (TypeScript Interface)

```typescript
export type FanTag = 'home' | 'away' | 'neutral'

export type AreaCategory =
  | 'VIP/테이블석'
  | '내야 지정석 (K9/K8)'
  | '내야 일반석 (K5/K3)'
  | '특화석 (익사이팅/서프라이즈)'
  | '외야석'
  | '특별 패밀리석'

export type SeatZone = {
  id: string                    // 고유 ID (예: 'k9-3base', 'k9-1base')
  category: AreaCategory        // 구역 대분류
  zoneName: string              // 구역 구분명 (예: 'K9석 (3루 홈)', '챔피언석')
  blockName: string             // 블록명 (예: '3루 하단 114~121블록', '포수 후면 중앙 특별석')
  weekdayPrice: number          // 평일 1석 가격 (원)
  weekendPrice: number          // 주말/공휴일 1석 가격 (원)
  cheerScore: number            // 응원 점수 (0 ~ 5)
  viewScore: number             // 시야 점수 (0 ~ 5)
  comfortScore: number          // 편의 점수 (0 ~ 5)
  fanTag: FanTag                // 홈('home') / 원정('away') / 중립('neutral')
  features: string[]            // 구역별 특징 태그 배열
  maxParty: number              // 권장 최대 수용 인원 (기본 40)
}
```
