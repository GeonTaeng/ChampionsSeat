# Sprint 2: 입력 영역 UI & 폼 유효성 검증 시스템 (완료)

## 1. 스프린트 목표
PRD 3-1 화면 명세의 5대 입력 항목(응원팀, 방문일, 방문 인원, 총 예산, 3대 선호도 슬라이더)을 세련되고 직관적인 UI로 구현하고, PRD 5-1(필수값 누락) 및 5-5(형식/범위 오류) 예외 처리 규칙을 완벽하게 적용합니다.

---

## 2. 작업 내역 (Tasks)

### Task 2-1: 입력 폼 컴포넌트 설계 및 구현
- **대상 파일**: `components/input-section.tsx`
- **필드별 UI 구성**:
  1. **① 응원팀 (`cheer_team`)**:
     - 라디오/세그먼트 버튼 (홈: KIA 타이거즈 - 3루 방면 / 어웨이: 원정팀 - 1루 방면)
     - 1줄 헬퍼 텍스트: *"홈은 3루 응원석, 어웨이는 1루 원정석 위주로 추천해드려요."*
  2. **② 방문일 유형 (`visit_day_type`)**:
     - 라디오/세그먼트 버튼 (평일: 화~목 / 주말·공휴일: 금~일/공휴일)
     - 1줄 헬퍼 텍스트: *"평일과 주말·공휴일은 좌석 가격이 다르게 적용됩니다."*
  3. **③ 방문 인원 (`party_size`)**:
     - 숫자 스테퍼 (+ / - 버튼 및 직접 입력 지원, 범위: 1~40 정수, 기본값: 1)
     - 1줄 헬퍼 텍스트: *"함께 관람할 인원을 1~40명 사이로 정해주세요."*
  4. **④ 총 예산 (`total_budget`)**:
     - 원(KRW) 단위 숫자 입력 필드 (천 단위 콤마 자동 서식화, 퀵 예산 증액 버튼: +1만, +3만, +5만, +10만 및 초기화 제공)
     - 1줄 헬퍼 텍스트: *"인원 전체가 함께 지불할 좌석 총액을 입력하세요 (원)."*
  5. **⑤ 선호도 슬라이더 3종 (`pref_cheer`, `pref_view`, `pref_comfort`)**:
     - 응원 선호도: 0~5점 (기본값: 3, 툴팁 도움말 완비)
     - 시야 선호도: 0~5점 (기본값: 3, 툴팁 도움말 완비)
     - 편의 선호도: 0~5점 (기본값: 3, 툴팁 도움말 완비)

### Task 2-2: 입력 유효성 검증(Validation) 엔진 구현
- **대상 파일**: `lib/validation.ts`
- **검증 규칙 구현**:
  - **PRD 5-1 필수값 미입력 검증**:
    - `cheer_team` 미선택 시: *"응원팀을 선택해주세요"*
    - `visit_day_type` 미선택 시: *"방문일 유형을 선택해주세요"*
    - `budgetRaw` 공란 시: *"예산을 입력해주세요"*, 0원 이하 시: *"1원 이상의 예산을 입력해주세요"*
  - **PRD 5-5 형식/범위 초과 검증 및 Clamp 처리**:
    - `party_size`가 1 미만 시: *"1명 이상의 정수를 입력해주세요"*, 40 초과 시: *"인원은 최대 40명까지 입력 가능합니다"*
    - `budgetRaw`에 문자 입력 시: *"예산은 숫자만 입력해주세요"*
    - 슬라이더 값 범위(0~5) clamp 보정

### Task 2-3: 인터랙션 & 포커스/스크롤 피드백 구현
- **대상 파일**: `app/page.tsx`, `components/input-section.tsx`
- **구현 내용**:
  - 추천 버튼 클릭 시 유효성 검증 실패할 경우:
    1. 추천 로직 실행 즉시 차단 및 기존 결과 유지
    2. 에러가 발생한 첫 번째 필드로 화면 자동 부드러운 스크롤(`scrollIntoView({ behavior: 'smooth', block: 'center' })`) 및 `focus()` 이동
    3. 해당 입력 필드 테두리를 에러 색상(`border-destructive`) 및 `aria-invalid="true"`로 강조
    4. 필드 하단에 인라인 에러 메시지 애니메이션 노출
  - 사용자가 값을 수정하면 즉시 인라인 에러가 해제되는 반응형 UX

### Task 2-4: 유효성 검증 단위 테스트 및 빌드 검증
- **대상 파일**: `lib/__tests__/validation.test.ts`
