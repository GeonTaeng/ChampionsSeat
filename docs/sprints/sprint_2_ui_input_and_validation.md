# Sprint 2: 입력 영역 UI & 폼 유효성 검증 시스템

## 1. 스프린트 목표
PRD 3-1 화면 명세의 5대 입력 항목(응원팀, 방문일, 방문 인원, 총 예산, 3대 선호도 슬라이더)을 세련되고 직관적인 UI로 구현하고, PRD 5-1(필수값 누락) 및 5-5(형식/범위 오류) 예외 처리 규칙을 완벽하게 적용합니다.

---

## 2. 작업 내역 (Tasks)

### Task 2-1: 입력 폼 컴포넌트 설계 및 구현
- **대상 파일**: `components/seat-finder/InputSection.tsx` 및 하위 컨트롤
- **필드별 UI 구성**:
  1. **① 응원팀 (`cheer_team`)**:
     - 라디오/세그먼트 버튼 (홈: KIA 타이거즈 / 어웨이: 원정팀)
     - 1줄 헬퍼 텍스트: *"응원하시는 팀에 맞춰 최적의 응원석/원정석을 배치합니다."*
  2. **② 방문일 유형 (`visit_day_type`)**:
     - 라디오/세그먼트 버튼 (평일 / 주말·공휴일)
     - 1줄 헬퍼 텍스트: *"평일/주말 기준 요금이 다르게 적용됩니다."*
  3. **③ 방문 인원 (`party_size`)**:
     - 숫자 스테퍼 (+ / - 버튼 및 직접 입력 지원, 범위: 1~40 정수, 기본값: 1)
     - 1줄 헬퍼 텍스트: *"함께 관람할 총 인원수(1~40명)를 입력하세요."*
  4. **④ 총 예산 (`total_budget`)**:
     - 원(KRW) 단위 숫자 입력 필드 (천 단위 콤마 자동 서식화, 퀵 예산 버튼 제공: +1만, +3만, +5만, +10만)
     - 1줄 헬퍼 텍스트: *"인원 전체가 지불할 좌석 총액을 입력하세요 (원)."*
  5. **⑤ 선호도 슬라이더 3종 (`pref_cheer`, `pref_view`, `pref_comfort`)**:
     - 응원 선호도: 0~5점 (기본값: 3, 레이블: 조용히 관람 ~ 열정적 응원)
     - 시야 선호도: 0~5점 (기본값: 3, 레이블: 전체 조망 ~ 초근접 시야)
     - 편의 선호도: 0~5점 (기본값: 3, 레이블: 가성비 우선 ~ 최고 편의/테이블)

### Task 2-2: 입력 유효성 검증(Validation) 엔진 구현
- **대상 파일**: `lib/utils/validation.ts`
- **검증 규칙 구현**:
  - **PRD 5-1 필수값 미입력 검증**:
    - `cheer_team` 미선택 시: *"응원팀을 선택해주세요."*
    - `visit_day_type` 미선택 시: *"방문일 유형을 선택해주세요."*
    - `total_budget` 공란 또는 0 이하일 시: *"1원 이상의 예산을 입력해주세요."*
  - **PRD 5-5 형식/범위 초과 검증 및 Clamp 처리**:
    - `party_size`가 1 미만이거나 40 초과 시: *"인원은 1명 이상 40명 이하로 입력해주세요."*
    - `total_budget`에 숫자가 아닌 문자 또는 음수 입력 시 반려 및 에러
    - 슬라이더 값 범위(0~5) 강제 clamp 보정

### Task 2-3: 인터랙션 & 포커스/스크롤 피드백 구현
- **구현 내용**:
  - 추천 버튼 클릭 시 유효성 검증 실패할 경우:
    1. 추천 로직 실행 즉시 차단
    2. 에러가 발생한 첫 번째 필드로 화면 자동 부드러운 스크롤(`scrollIntoView({ behavior: 'smooth' })`) 및 `focus()` 이동
    3. 해당 입력 필드 테두리를 에러 색상(Red/Destructive)으로 강조
    4. 필드 하단에 인라인 에러 메시지 텍스트 애니메이션 렌더링
  - 사용자가 값을 수정하면 즉시 인라인 에러가 해제되는 반응형 UX

## 3. 완료 정의 (Definition of Done)
- [ ] 5개 입력 항목이 PRD에 명시된 타입/기본값/설명과 완벽히 일치
- [ ] 필수 항목 미입력 상태에서 실행 시 5-1 규칙(인라인 에러 + 포커스 이동) 정상 동작
- [ ] 범위 초과 입력(40명 초과, 음수 예산 등) 시 5-5 규칙 정상 동작
- [ ] 모바일/데스크톱 모두에서 터치 및 슬라이더 조작이 원활하게 작동
