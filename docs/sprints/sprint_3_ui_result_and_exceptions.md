# Sprint 3: 결과 화면, 로딩 상태 & 예외 처리 뷰 (완료)

## 1. 스프린트 목표
추천 실행 버튼 인터랙션 및 로딩/지연 상태를 구현하고, 산출된 TOP 3 추천 결과 카드, 입력 요약 바, 그리고 PRD 5-2(예산 초과), 5-4(연산 실패/재시도), 5-6(데이터 누락) 등 모든 예외 화면을 완벽하게 구현합니다.

---

## 2. 작업 내역 (Tasks)

### Task 3-1: 실행 버튼 및 로딩 상태 제어 (PRD 3-2, 5-3)
- **대상 파일**: `components/input-section.tsx`, `components/result-loading-state.tsx`, `app/page.tsx`
- **구현 내용**:
  - `좌석 추천받기` 버튼 클릭 즉시 비활성화 + *"추천 좌석 찾는 중..."* 로딩 상태 전환 (중복 클릭/연산 방지)
  - **PRD 5-3 지연 로딩 처리**:
    - 2초 이상 소요 시: 분석 중 스피너 + 스켈레톤 UI 노출
    - 8초 이상 지연 시: *"예상보다 시간이 걸리고 있어요. 잠시만 기다려주세요."* 보조 안내 문구 노출
    - 15초 초과 시: 타임아웃 발생 → PRD 5-4 실패 상태로 자동 전환
  - 로딩 중 입력 폼 전체 비활성화(`disabled={isLoading}`)로 입력값-결과 불일치 원천 차단

### Task 3-2: 정상 추천 결과 영역 (Result Section) UI 구현 (PRD 3-3)
- **대상 파일**: `components/seat-result-card.tsx`, `app/page.tsx`
- **구현 내용**:
  1. **상단 입력 요약 바 (Summary Bar)**:
     - *"응원팀: KIA 타이거즈 | 방문: 주말·공휴일 | 인원: 2명 | 예산: 100,000원"* 1줄 요약 뱃지 노출
  2. **TOP 3 좌석 카드 (1위 Gold, 2위 Silver, 3위 Bronze)**:
     - **1위**: `BEST MATCH` 왕관 뱃지, Gold 링 강조, 그라데이션 글로우 효과
     - **구역명 & 블록명**: 선명한 헤드라인 및 블록 정보 노출
     - **예상 총금액**: `1석 가격 × 인원수` 계산 결과 강조 (카운트업 애니메이션 적용)
     - **점수 게이지**: 응원 열기 / 경기 시야 / 좌석 편의 3대 게이지 시각화
     - **AI 추천 사유 박스**: 선호도 1~2위 언급 + 원정 응원 가능성 + 인원/금액 요약
     - **핵심 특징 태그**: `#포수바로뒤`, `#홈응원열기`, `#넓은테이블` 등 구역별 태그 노출

### Task 3-3: 예산 초과 안내 및 최소 필요 예산 가이드 뷰 (PRD 5-2)
- **대상 파일**: `components/budget-over-state.tsx`
- **구현 내용**:
  - 안내 문구: *"입력하신 예산으로는 조건에 맞는 좌석이 없어요."*
  - **최소 필요 예산 가이드**:
    - 응원팀 조건 반영 후 최저가 구역(외야 자유석 등) 기준 *"최소 {최소필요총액}원부터 예매 가능해요 ({구역명} 기준 예상 총금액)"* 노출
  - **"예산 다시 입력하기" 버튼**: 클릭 시 `total_budget` 입력 필드로 스무스 스크롤 및 자동 `focus()` 이동
  - 빈 카드나 0원 카드는 일체 렌더링하지 않음

### Task 3-4: 오류 및 재시도 상태 뷰 (PRD 5-4, 5-6)
- **대상 파일**: `components/error-state.tsx`, `components/no-data-state.tsx`
- **구현 내용**:
  - **PRD 5-4 연산 실패/재시도**:
    - *"좌석 추천을 불러오지 못했어요. 다시 시도해주세요."*
    - `다시 시도` 버튼 제공 (기존 입력값 100% 보존 상태에서 재실행)
    - 2회 연속 실패 시 *"일시적인 문제가 계속되고 있어요. 잠시 후 다시 시도해주세요."* 로 문구 자동 변경
    - 콘솔에만 기술 에러 로깅, 사용자 화면에는 스택 트레이스 비노출
  - **PRD 5-6 데이터셋 누락**:
    - *"현재 조건에 대한 좌석 정보를 찾을 수 없어요. 다른 조건으로 다시 시도해주세요."*
    - 예산 초과(5-2)와 혼동되지 않도록 최소 필요 예산 가이드 미노출

### Task 3-5: 빌드 및 렌더링 검증
- Next.js 프로덕션 빌드(`npm run build`) 에러 0건 통과
- DevStateToggle을 통한 각 상태(Success, Budget-over, No-data, Error, Loading) 수동/자동 검증 완료
