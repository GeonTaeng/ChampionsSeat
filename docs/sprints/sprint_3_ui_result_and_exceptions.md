# Sprint 3: 결과 화면, 로딩 상태 & 예외 처리 뷰

## 1. 스프린트 목표
추천 실행 버튼 인터랙션 및 로딩/지연 상태를 구현하고, 산출된 TOP 3 추천 결과 카드, 입력 요약 바, 그리고 PRD 5-2(예산 초과), 5-4(연산 실패/재시도), 5-6(데이터 누락) 등 모든 예외 화면을 완벽하게 구현합니다.

---

## 2. 작업 내역 (Tasks)

### Task 3-1: 실행 버튼 및 로딩 상태 제어 (PRD 3-2, 5-3)
- **대상 파일**: `components/seat-finder/ActionSection.tsx`
- **구현 내용**:
  - `좌석 추천받기` 버튼 디자인 및 호버/클릭 효과
  - 클릭 즉시 버튼 비활성화 + 스피너 + *"추천 좌석 찾는 중..."* 로딩 상태 전환 (중복 연산 방지)
  - 연산 지연 시 단계별 UX:
    - 2초 이상 소요 시: 로딩 인디케이터 유지
    - 8초 이상 소요 시: *"예상보다 시간이 걸리고 있어요. 잠시만 기다려주세요."* 보조 안내 문구 표시
    - 15초 초과 시: 타임아웃 발생 → 5-4 실패 화면으로 전환
  - 로딩 중 입력 폼 비활성화 처리로 데이터 불일치 방지

### Task 3-2: 정상 추천 결과 영역 (Result Section) UI 구현 (PRD 3-3)
- **대상 파일**: `components/seat-finder/ResultSection.tsx`, `SeatCard.tsx`
- **구현 내용**:
  1. **상단 입력 요약 바 (Summary Bar)**:
     - *"응원팀: KIA 타이거즈 | 방문: 주말 | 인원: 2명 | 예산: 50,000원"* 형태로 사용자가 입력한 조건 1줄 노출
  2. **TOP 3 좌석 카드 (1위, 2위, 3위)**:
     - **순위 뱃지**: Gold(1위), Silver(2위), Bronze(3위) 시각적 강조
     - **구역명 & 블록명**: 굵은 타이포그래피 (예: *K9석 - 3루 114~121블록*)
     - **예상 총금액**: `1석 가격 × 인원수` 계산 결과 강조 (예: *36,000원 / 2인 기준*)
     - **추천 사유 박스**: 선호도 및 홈/원정 특성을 반영한 1~3줄 추천 이유 텍스트
     - **핵심 특징 태그**: (예: *#응원단상앞*, *#홈응원열기*, *#탁트인시야*)

### Task 3-3: 예산 초과 안내 및 최소 필요 예산 가이드 뷰 (PRD 5-2)
- **대상 파일**: `components/seat-finder/BudgetExceededView.tsx`
- **구현 내용**:
  - 안내 문구: *"입력하신 예산으로는 조건에 맞는 좌석이 없어요."*
  - **최소 필요 예산 가이드**:
    - 응원팀 조건을 반영한 전체 좌석 중 `party_size` 기준 가장 저렴한 구역(예: 외야 자유석)의 총금액 계산
    - *"최소 {최소필요총액}원부터 예매 가능해요 ({최저가 구역명})"* 형태로 친절한 가이드 제공
  - **"예산 다시 입력하기" 버튼**: 클릭 시 `total_budget` 입력 필드로 스무스 스크롤 및 자동 포커스 이동
  - 빈 카드나 0원 카드는 일체 렌더링하지 않음

### Task 3-4: 오류 및 재시도 상태 뷰 (PRD 5-4, 5-6)
- **대상 파일**: `components/seat-finder/ErrorStateView.tsx`
- **구현 내용**:
  - **5-4 추천 로직/응답 실패 케이스**:
    - *"좌석 추천을 불러오지 못했어요. 다시 시도해주세요."* 에러 UI
    - `다시 시도` 버튼 제공 (기존 입력값 100% 보존 상태에서 재실행)
    - 2회 연속 실패 시: *"일시적인 문제가 계속되고 있어요. 잠시 후 다시 시도해주세요."* 로 문구 자동 변경
    - 콘솔에만 기술 에러 로깅, 사용자 화면에는 스택 트레이스 노출 방지
  - **5-6 데이터셋 누락 케이스**:
    - *"현재 조건에 대한 좌석 정보를 찾을 수 없어요. 다른 조건으로 다시 시도해주세요."*
    - 예산 부족(5-2)과 명확히 구분하여 최소 필요 예산 가이드는 미노출

- [ ] 예산 부족 시 5-2 규칙(최소 필요 예산 + 예산 수정 버튼 포커스) 정상 동작
